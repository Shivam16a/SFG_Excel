About This Project

This Student Management System is a web-based application designed to demonstrate how student data can be collected, managed, and stored in a Google Spreadsheet using a simple frontend interface.

The project is built using HTML, CSS, and JavaScript for the user interface, and Google Apps Script is used as a backend service to store and manage data in real time within a Google Sheet.

The main purpose of this project is to learn how form data from a website can be connected to a spreadsheet database, enabling operations such as adding, editing, deleting, and retrieving records dynamically.

This system also includes interactive features like search functionality, pagination, dark mode, and data visualization using charts, making it a complete beginner-friendly full-stack learning project.

Developer Information

This project is developed by Your Name as a learning-based web application.

It demonstrates the integration of frontend technologies (HTML, CSS, JavaScript) with Google Sheets using Google Apps Script as a backend service.
